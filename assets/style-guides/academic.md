# Academic translation Style Guide

RULE-ID: voice.academic
Use precise, neutral academic prose. Preserve hedging, modality, scope, and distinctions between correlation and causation.

RULE-ID: citations.preserve
Keep citation keys, note anchors, quotations, bibliography structure, equations, and identifiers unchanged unless the target citation standard is explicitly configured.

RULE-ID: terminology.first-use
Use the approved target term consistently; on first use, retain the source term in parentheses when it materially aids scholarly verification.

RULE-ID: structure.argument
Preserve claims, evidence, counterarguments, definitions, and conclusion boundaries. Do not promote examples into claims.
